data-split

Resizable split panels with responsive layouts

Installation

<script type="module">
import { load, apply } from 'https://cdn.jsdelivr.net/gh/starfederation/datastar@main/bundles/datastar.js';
import SplitPlugin from 'https://cdn.jsdelivr.net/gh/ndendic/data-satellites@master/dist/min/split.min.js';

SplitPlugin.setConfig({
    signal: 'split',
    defaultMinSize: 10,
    responsive: false
});

load(SplitPlugin);
apply();
</script>

API Reference

Configuration

SplitPlugin.setConfig({
    signal: 'split',              // Signal prefix
    defaultMinSize: 10,           // Min panel size (%)
    responsive: false,            // Auto switch h/v on resize
    responsiveBreakpoint: 768     // Breakpoint for responsive
});

Syntax

<!-- Format: data-split="signal:direction:sizes" -->
<div data-split="mysplit:horizontal:50,50"></div>
<div data-split="mysplit:vertical:30,70"></div>
<div data-split="mysplit:horizontal:25,50,25"></div>

Signals Created

${signal}_sizes       - Array: panel sizes in percentages
${signal}_direction   - String: 'horizontal' or 'vertical'

CSS Customization

:root {
    --split-handle-size: 8px;
    --split-handle-color: #ccc;
    --split-handle-hover-color: #3b82f6;
    --split-handle-active-color: #2563eb;
}

Features

  • Horizontal and vertical splits
  • Multiple panels (2+)
  • Nested splits for complex layouts
  • Touch support for mobile
  • Responsive mode (auto switch direction)
  • Corner handles for intersecting splits
  • Minimum size constraints
  • Signal integration for reactive layouts
