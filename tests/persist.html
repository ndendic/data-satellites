data-persist

Persist Datastar signals to localStorage / sessionStorage

Installation

<script type="module">
import { load, apply } from 'https://cdn.jsdelivr.net/gh/starfederation/datastar@main/bundles/datastar.js';
import PersistPlugin from 'https://cdn.jsdelivr.net/gh/ndendic/data-satellites@master/dist/min/persist.min.js';

load(PersistPlugin);
apply();
</script>

Basic Usage

Boolean attribute persists all signals found on the page (via explicit list below and any discovered via data-signals-*).

Profile

Theme

<body data-signals="{name: 'Ada', age: 33, theme: 'light'}" data-persist>
    <input data-on-input="$name = $event.target.value" data-value="$name" />
    <button data-on-click="$theme = 'dark'">Dark</button>
</body>

Namespaced Keys

Use a suffix to isolate storage: data-persist-profile saves under a separate key.

Profile Notes (localStorage)

Key: satellite-persist-profile

Session Notes (sessionStorage)

Key: satellite-persist-session (sessionStorage)
<div data-signals-notes="''" data-persist-profile="notes"></div>
<div data-signals-sessionNote="''" data-persist-session.session="sessionNote"></div>

Explicit List vs Wildcard

If a value is provided, only listed signals are persisted. Otherwise, all data-signals-* discoveries are persisted.

Explicit List

Only name + email are stored

Wildcard

All discovered cart signals are stored
<div data-persist-account="user_name, user_email"></div>
<div data-persist-cart></div>

Throttling

Use .immediate for no debounce, or __throttle.N to debounce writes.

Immediate

Debounced (1000ms)

<div data-persist-fast.immediate="fast"></div>
<div data-persist-slow__throttle.1000="slow"></div>

Inspect Storage

Values are stored under keys starting with satellite-persist. Refresh to verify persistence.

Open DevTools → Application → Storage to inspect.

API Reference

Attributes

<!-- Persist all discovered signals (boolean attribute) -->
<div data-persist></div>

<!-- Persist only listed signals -->
<div data-persist="name, age"></div>

<!-- Namespaced key (stored as satellite-persist-profile) -->
<div data-persist-profile="notes"></div>

<!-- Session storage -->
<div data-persist.session></div>

<!-- Throttle writes (ms) -->
<div data-persist__throttle.1000></div>

<!-- Immediate writes (no debounce) -->
<div data-persist.immediate></div>
