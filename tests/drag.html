data-draggable

Advanced drag & drop with freeform and sortable modes

Installation

<script type="module">
import { load, apply } from 'https://cdn.jsdelivr.net/gh/starfederation/datastar@main/bundles/datastar.js';
import DragPlugin from 'https://cdn.jsdelivr.net/gh/ndendic/data-satellites@master/dist/min/drag.min.js';

DragPlugin.setConfig({
    signal: 'drag',
    mode: 'freeform',
    throttleMs: 16,
    constrainToParent: false
});

load(DragPlugin);
apply();
</script>

API Reference

Configuration

DragPlugin.setConfig({
    signal: 'drag',              // Signal prefix (default: 'drag')
    mode: 'freeform',            // 'freeform' or 'sortable'
    throttleMs: 16,              // Update throttle in ms
    constrainToParent: false     // Keep within parent bounds
});

Signals Created

$drag_is_dragging      - Boolean: currently dragging
$drag_element_id       - String: ID of dragged element
$drag_x                - Number: current X position
$drag_y                - Number: current Y position
$drag_drop_zone        - String: current drop zone name
$drag_zone_{name}_items - Array: items in named zone

Attributes

<!-- Make element draggable -->
<div data-draggable>Drag me</div>

<!-- Define drop zone -->
<div data-drop-zone="my-zone">...</div>

<!-- Container for drag tracking -->
<div data-draggable>
    <!-- Nested draggables -->
</div>
