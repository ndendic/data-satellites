Advanced scroll tracking with velocity, direction, and visibility

Installation

<script type="module">
import { load, apply } from 'https://cdn.jsdelivr.net/gh/starfederation/datastar@main/bundles/datastar.js';
import ScrollPlugin from 'https://cdn.jsdelivr.net/gh/ndendic/data-satellites@master/dist/min/scroll.min.js';

load(ScrollPlugin);
apply();
</script>

Global Scroll Tracking

Track scroll position, velocity, and direction automatically

<!-- Add to body or any element -->
<body data-scroll>

<!-- Progress bar -->
<div style="width: 100%">
    <div data-style-width="`${$scroll_page_progress}%`"></div>
</div>

<!-- Scroll info -->
<div data-text="`Position: ${$scroll_y}px`"></div>
<div data-text="`Direction: ${$scroll_direction}`"></div>
<div data-text="`Velocity: ${$scroll_velocity}`"></div>

API Reference

Global Signals

$scroll_x              - Number: Horizontal scroll position
$scroll_y              - Number: Vertical scroll position
$scroll_direction      - String: 'up', 'down', or 'none'
$scroll_velocity       - Number: Scroll speed (px/s)
$scroll_delta          - Number: Change since last update
$scroll_page_progress  - Number: Page scroll progress (0-100%)
$scroll_is_top         - Boolean: At top of page
$scroll_is_bottom      - Boolean: At bottom of page

Element-Specific Signals

$scroll_visible        - Boolean: Element in viewport
$scroll_visible_percent - Number: Visible percentage (0-100%)
$scroll_progress       - Number: Element scroll progress
$scroll_element_top    - Number: Element top position
$scroll_element_bottom - Number: Element bottom position

Smooth Scrolling

<!-- Add smooth modifier for interpolated values -->
<div data-scroll__smooth>
    <!-- Smoothed signals available:
         $scroll_y_smoothed
         $scroll_velocity_smoothed
    -->
</div>

Throttling

<!-- Adjust update frequency -->
<div data-scroll__throttle.100></div>  <!-- Every 100ms -->
<div data-scroll__throttle.16></div>   <!-- 60 FPS -->
<div data-scroll></div>                <!-- Default: 100ms -->

Common Use Cases

<!-- Progress bar -->
<div data-style-width="`${$scroll_page_progress}%`"></div>

<!-- Fade in on scroll -->
<div data-scroll 
     data-class-visible="$scroll_visible_percent > 50"></div>

<!-- Parallax effect -->
<div data-scroll
     data-style-transform="`translateY(${$scroll_progress * 0.5}px)`"></div>

<!-- Sticky header -->
<header data-scroll
        data-class-sticky="$scroll_y > 100"></header>

<!-- Back to top button -->
<button data-scroll
        data-show="$scroll_y > 500">Back to Top</button>
