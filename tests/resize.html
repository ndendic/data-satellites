Installation

<script type="module">
import { load, apply } from 'https://cdn.jsdelivr.net/gh/starfederation/datastar@main/bundles/datastar.js';
import ResizePlugin from 'https://cdn.jsdelivr.net/gh/ndendic/data-satellites@master/dist/min/resize.min.js';

load(ResizePlugin);
apply();
</script>

API Reference

Signals Created

$resize_width              - Number: Element width in pixels
$resize_height             - Number: Element height in pixels
$resize_window_width       - Number: Window width in pixels
$resize_window_height      - Number: Window height in pixels
$resize_aspect_ratio       - Number: Width/height ratio
$resize_current_breakpoint - String: xs, sm, md, lg, xl, 2xl
$resize_is_mobile          - Boolean: Width < 768px
$resize_is_tablet          - Boolean: 768px <= Width < 1024px
$resize_is_desktop         - Boolean: Width >= 1024px

Breakpoints

xs    - < 640px
sm    - 640px  - 768px
md    - 768px  - 1024px
lg    - 1024px - 1280px
xl    - 1280px - 1536px
2xl   - >= 1536px

Throttling & Debouncing

<!-- Throttle updates (default: 150ms) -->
<div data-resize__throttle.100></div>

<!-- Debounce updates (wait for resize to finish) -->
<div data-resize__debounce.300></div>

<!-- RAF throttle (60 FPS) -->
<div data-resize__throttle.16></div>

Common Use Cases

<!-- Responsive navigation -->
<nav data-show="$resize_is_desktop">Desktop Menu</nav>
<button data-show="$resize_is_mobile">☰ Menu</button>

<!-- Conditional content -->
<div data-show="$resize_width > 600">Wide content</div>

<!-- Dynamic styling -->
<div data-style-font-size="`${$resize_width / 20}px`"></div>

<!-- Breakpoint classes -->
<div data-class-mobile="$resize_is_mobile"
     data-class-desktop="$resize_is_desktop"></div>

<!-- Execute on resize -->
<div data-resize="console.log('Resized!')"></div>

Features

  • ResizeObserver API for efficient tracking
  • Window and element resize observation
  • Built-in responsive breakpoints
  • Aspect ratio calculation
  • Throttle and debounce options
  • Mobile/tablet/desktop helpers
  • Automatic fallback for older browsers
