⌨️

Grid System

Optional grid with major and minor lines

API Reference

Configuration

CanvasPlugin.setConfig({
    signal: 'canvas',              // Signal prefix
    enablePan: true,               // Enable panning
    enableZoom: true,              // Enable zooming
    minZoom: 0.1,                  // Minimum zoom level
    maxZoom: 10,                   // Maximum zoom level
    touchEnabled: true,            // Touch/pinch support
    contextMenuEnabled: true,      // Right-click menu
    spacebarPan: true,             // Spacebar + drag to pan
    middleClickPan: true,          // Middle mouse to pan
    enableGrid: true,              // Show grid
    gridSize: 100,                 // Major grid size (px)
    gridColor: '#e0e0e0',          // Major grid color
    minorGridSize: 20,             // Minor grid size (px)
    minorGridColor: '#f0f0f0'      // Minor grid color
});

Signals Created

$canvas_pan_x              - Number: X pan offset
$canvas_pan_y              - Number: Y pan offset
$canvas_zoom               - Number: Zoom level (1.0 = 100%)
$canvas_reset_view         - Function: Reset to default
$canvas_zoom_in            - Function: Zoom in
$canvas_zoom_out           - Function: Zoom out
$canvas_context_menu_x     - Number: Right-click X (canvas coords)
$canvas_context_menu_y     - Number: Right-click Y (canvas coords)
$canvas_context_menu_screen_x  - Number: Right-click X (screen coords)
$canvas_context_menu_screen_y  - Number: Right-click Y (screen coords)

Attributes

<!-- Viewport container -->
<div data-canvas-viewport data-onCanvas="true">
    <!-- Canvas container (receives transform) -->
    <div data-canvas-container>
        <!-- Your canvas content here -->
    </div>
</div>

Keyboard Shortcuts

Space + Drag       - Pan the canvas
Mouse Wheel        - Zoom in/out
Middle Click + Drag - Pan the canvas
Ctrl/Cmd + +       - Zoom in
Ctrl/Cmd + -       - Zoom out
Ctrl/Cmd + 0       - Reset view
Right Click        - Context menu (updates signals)
